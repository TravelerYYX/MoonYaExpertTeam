# MoonYa Index 重构说明

## 背景

原 `index.php` 是一个超过 14,000 行的单文件，包含 HTML、CSS、JavaScript 混合内容，难以维护。为提升代码可维护性，将该文件按功能模块拆分为多个子文件。

## 重构原则

1. **字节级精确保留**: 所有原文件的行（包括空行、注释、缩进）必须完整保留在某个新文件中
2. **不重叠不遗漏**: 各文件行号范围连续无重叠，所有原文件内容都被分配
3. **无字符增删**: 仅做"移动"，不添加、删除或修改任何字符
4. **安全边界**: 仅在函数结束、代码块结束、注释边界等安全位置切分

## 重构前后对比

|------|--------|--------|
| 文件数 | 1 | 30 (含 3 个目录 + 20 个占位) |

| 总行数 | 14,215 | 14,233（业务文件）+ 54（新 index.php）|

## 拆分策略

### CSS 拆分 (15 段)

按 `/* ===== 区块名 ===== */` 注释切分，确保每个 CSS 区块（reset、auth、sidebar、animations、music 等）独立成文件。首尾文件的 `<style>` 和 `</style>` 标签在 css-01-base.php 和 css-15-result.php 中已移除以避免在新 index.php 中重复。

### HTML 拆分 (7 段)

按 HTML 区块切分：
- `container` - 容器、浮动按钮
- `sidebar` - 侧边栏
- `auth-modal` - 登录注册弹窗
- `main-content` - 右侧主内容、输入框
- `toast` - Toast 提示
- `dynamic-island` - 灵动岛 HTML
- `video-player` - 视频播放器

### JS 拆分 (7 段)

按功能边界（函数结束位置、注释边界）切分：
- `script-1a-vars` - 全局变量、模型/模式选择器
- `script-1b-features` - Toast、音乐、星座、天气等
- `script-1c-save` - 保存/加载对话、语音播报
- `script-1d-dom` - DOM 初始化、事件处理
- `script-1e-rest` - 消息发送、流式响应、渲染
- `script-2-island` - 灵动岛 IIFE
- `script-2-download` - 文件下载工具

### 占位文件 (20 个)

为保持目录结构清晰，创建了 3 类占位文件：
- `utils/` (6): 工具函数（实际逻辑保留在对应 modules）
- `components/` (8): UI 组件（实际逻辑保留在对应 modules/layouts）
- `data/` (6): 数据模型（实际数据保留在对应 modules）

## 实施步骤

1. 从备份读取原始 `index.php`（14,215 行 / 690,444 字节）
2. 按功能切分为 29 个 PHP 业务分段文件
3. 修复首/末 CSS 文件的 `<style>` 标签以适配新 index.php 的结构
4. 创建 20 个占位符文件（utils/components/data）
5. 编写新的 54 行 `index.php`，通过 `<?php include __DIR__ . '/script/MoonYa-index/...' ?>` 引入各分段
6. 验证所有 PHP 文件语法正确

## 注意事项

- 拆分点全部基于功能注释和代码块边界，无中途中断
- 所有空行都被正确保留在所属分段中
- 末尾无换行（`</html>` 后）的特性在拼接时通过 `[String]::Join("\n", $slice) + "\n"` 正确处理
- PHP 包含使用 `__DIR__` 绝对路径，避免相对路径解析问题
